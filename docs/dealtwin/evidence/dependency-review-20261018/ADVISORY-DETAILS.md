# Remaining advisory detail and embedded-copy scope

This is a static extension of the previous inventory, not a new exploit validation. Current npm audit:20 affected package aggregates /9 unique GHSA URLs. The original32-URL inventory also covers23 Undici/ws advisories in embedded old copies outside current external package counts. Candidate-only Undici7.28.0 adds one different advisory; do not add it to the current installed audit.

## Embedded paths

- **U1:** `node_modules/@cloudflare/vite-plugin/dist/index.mjs` embeds Undici7.24.8.
- **U2:** `node_modules/wrangler/wrangler-dist/cli.js` embeds Undici7.24.8.
- **W:** the same Wrangler bundle embeds ws8.18.0.
- External `node_modules/undici`7.29.1 and `node_modules/ws`8.21.0 are fixed for these supplied claims.
- These are dev/build/deploy-tooling programs. No imported caller from the built Node/PostgreSQL request handler was found; invoking the CLI/dev target is a different surface.
- Tooling fetch callers are real, but a declared library export does not prove optional SOCKS/cache/retry/BalancedPool/WebSocketStream configuration. No Cloudflare network call, attack payload or browser was executed.

## Candidate-only advisory
