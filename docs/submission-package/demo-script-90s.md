## Recording notes

- Keep the transcript shot moving; do not wait on every line.
- Use a restrained cursor halo only for clicks.
- Crop no badges, amounts, dates, guide controls, or Demo Data labels.
- If the timing slips, stop the take and use **Presentation Fallback** rather than accelerating the edit unnaturally.
