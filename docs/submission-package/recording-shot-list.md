## Capture discipline

- Use Fast Demo; reserve Presentation Fallback and Instant Result for recovery takes.
- Reset Demo Data before recording and verify the recommended row is highlighted.
- Disable browser and operating-system notifications.
- Use 90% or 100% browser zoom at a minimum resolution of 1440 × 900.
- Hide the bookmark bar and all personal tabs; never show an API key.
- Move the cursor slowly, use simple cuts, and avoid excessive digital zoom.
