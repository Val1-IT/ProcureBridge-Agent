# Three-Minute Backup Demo Script

Record at 1440 × 900 using Fast Demo. All customers and outcomes are Demo Data.

## 0–20 seconds — Problem and solution

**Screen:** Landing page, headline, value cards, and Demo Data label.

**Voice-over:** “Receivables work is fragmented across invoice review, customer calls, notes, follow-ups, and dispute handling. ProcureBridge connects those steps. CALL-E executes an approved conversation, while Arvanta turns the result into a structured action under human control.”

## 20–105 seconds — Promise-to-pay scenario

Open the guided demo and choose PT Sinar Jaya Retail. Show `INV-2026-0812`, Rp12,500,000 outstanding, 18 days overdue, risk score, and recommended action. Open the AI briefing and highlight history, objective, negotiation limit, AI disclosure, and both mandatory approval checks.

**Voice-over:** “The call is locked until human approval and all guardrails pass: consent, Do Not Contact, allowed hours, same-day contact, open disputes, phone validity, and invoice validity.”

Start CALL-E in Fast Demo. Show the AI disclosure, a few decisive transcript lines, live stage, sentiment, intent, and extracted entities. Continue to result review.

**Voice-over:** “The mock provider exercises the same adapter boundary as CALL-E and remains visibly labeled simulation. The conversation produces a draft promise of Rp7.5 million on 10 August, with follow-up on 11 August. Only a human approval creates the operational commitment; the invoice amount itself is not changed.”

Approve and show Promise Tracker and the latest Audit Log entries.

## 105–130 seconds — Dispute scenario

Reset Demo Data, return to Collection Queue, and select CV Maju Teknik. Use Instant Result if needed. Show the dispute result and approve it.

**Voice-over:** “A different branch detects a quantity mismatch. The agent stops payment negotiation. Human approval creates a dispute, changes the invoice status to Disputed, and suppresses another collection call while the issue is open.”

## 130–145 seconds — Failed-contact scenario

Reset and select PT Nusantara Distribusi. Show the failed-contact result and follow-up.

**Voice-over:** “When the authorized contact is unavailable, the agent avoids disclosing invoice details and proposes only a callback. No promise or financial action is fabricated.”

## 145–165 seconds — Architecture and technical notes

Show `/architecture`, then `/technical-notes`.

**Voice-over:** “Pure state machines govern approvals, calls, and results. The provider adapter isolates CALL-E, while the webhook boundary validates events, deduplicates IDs, handles stale delivery, and records audit evidence. Supabase is prepared but optional for the browser demo.”

## 165–175 seconds — Reliability and safety

Show **Presentation Fallback**, speed selector, Reset Demo Data, and export controls.

**Voice-over:** “Fast Demo, Instant Result, deterministic reset, masked exports, and explicit fallback keep the presentation reliable without pretending simulation is live telephony.”

## 175–180 seconds — Closing

Return to the landing headline.

**Voice-over:** “Arvanta turns CALL-E conversations into controlled, structured, and auditable recovery actions.”

**Overlay:** Human-controlled voice-to-recovery workflow • Demo Data
